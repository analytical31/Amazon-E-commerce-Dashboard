# Amazon E-Commerce Analysis Dashboard | Power BI</br>
## Project Overview</br>
The Amazon E-Commerce Analysis Dashboard is a comprehensive Power BI solution designed to analyze sales performance, customer behavior, product returns, and delivery efficiency. This interactive dashboard enables stakeholders to monitor key business metrics, identify trends, and make data-driven decisions to improve profitability and customer satisfaction.</br>


## Project Objectives</br>
Analyze overall sales performance across different product categories.</br>
Understand customer purchasing behavior and preferences.</br>
Monitor product return rates and revenue loss.</br>
Evaluate delivery performance and operational efficiency.</br>
Identify high-performing products, categories, and locations.</br>
Provide actionable insights through interactive visualizations.</br>
